A deterministic chess engine in at most 4 KB of Python: negamax alpha-beta search with a transposition table, null-move pruning, late-move reduction, killer moves and a quiescence search, playing the make.fun house gauntlet over the env API on a fixed node budget, never a clock.

## Run it

```sh
MAKEFUN_ENV_URL=<env origin> python3 main.py
```
